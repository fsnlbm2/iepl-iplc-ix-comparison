## 先搞清楚：企业远程办公专线有哪几种形态

市面上打着"专线"旗号的产品大致分三类，交付方式完全不同：

- **专线 VPS**：商家交付一台带专线路径的服务器，团队通过远程桌面或 SSH 连上去，在服务器里运行业务程序，流量从专线出口发出。Mkcloud 就是这种形态。
- **SD-WAN / 硬件专线**：在办公室部署设备，把整个办公网络的流量引导到跨境路径。适合整团队、固定办公场所的场景，价格也高一个量级。
- **机场 / 共享节点**：多用户共享 IP 和带宽，个人使用方便，但 IP 干净度和带宽稳定性都没有保障，不适合承载企业业务。

三者的成本差距很大，选错形态会白花钱。判断标准其实很简单：**如果你的业务程序（店铺后台、API 客户端、浏览器环境）可以装在一台服务器里跑，专线 VPS 就够用；如果必须是"整间办公室的所有设备都走专线"，那需要的是硬件方案，而不是这篇文章讨论的产品。**

Mkcloud 官方知识库对这一点说得很直白：它交付的是 VPS 和对应出站线路，不是可供企业自行接入办公室的裸专线。出口只负责向外访问，**不接受外部连入**——公开网站、支付回调、邮件接收这类需要公网入站的服务，用这个产品承载不了。

## Mkcloud 是谁，产品线覆盖哪些方向

Mkcloud 是一家专注跨境网络的专线服务商，提供 IEPL、IPLC、IX 三类跨境专线 VPS，覆盖香港、日本、美国三个海外出口方向，外加上海 CN2 国内优化线路。每台 VPS 都分配 **1 个独立入口 IP 和 1 个独立出口 IP**，也就是所谓的单端双独立 IP——这一点对电商多账号、账号隔离类需求比较关键，因为共享带宽套餐也给独立 IP，不存在"买共享套餐就掉进共享 IP 池"的问题。

三个线路名词别搞混，但也不必神化：

- **IEPL**（以太网专线）：点对点独享信道，广港方向用的就是它。
- **IPLC**（国际私有租用电路）：传统跨境专用线路，沪港、沪日、沪美属于这类。
- **IX**（互联网交换方向）：通过云厂商网络接入，不走本地宽带直连，深港、沪港 IX、沪日 IX、沪美 IX 属于这类。

Mkcloud 自己的知识库特别强调：IEPL、IPLC、IX 是不同的产品和技术名称，**不能直接当作"稳定性从低到高"的排行榜**。选型的正确顺序是先确定出口地区和接入条件，再比较带宽和流量。

## 怎么按办公场景选线路

Mkcloud 知识库里有一张"60 秒选择表"，逻辑值得借用。给远程团队选线路，依次回答五个问题就够了：

1. **业务目标在哪**：团队主要访问日本平台选沪日，美国业务选沪美，香港出口通用性最强。
2. **从哪接入**：本地宽带直连选直连款，已有阿里云、腾讯云等云厂机器选 IX。
3. **人在哪个省份**：直连款一次绑定一个省份，只有绑定省份的 IP 能连入入口（可以自行切换）。异地分布的团队要特别注意这条限制——如果成员分散在多个省，要么统一绑定一个主力省份，要么直接走 IX 方案。
4. **看重峰值还是持续带宽**：见下一节。
5. **有没有高防、SLA、路由定制需求**：这些不属于默认套餐，下单前先提交工单确认。

举两个具体例子。团队在广东、主要操作香港方向的店铺后台：广港直连是第一候选，第三方测评记录显示广州入口 TCP ping 平均电信 34ms、联通 33ms、移动 38ms，日常操作流畅度基本没问题。团队在上海、需要跑日本平台的客户端测试：沪日 IPLC 共享 1TB 档 ¥358/月起步，端内参考 25~28ms。

## 共享还是独享：这是最容易算错的一步

Mkcloud 的"共享 / 独享"指的是**带宽模式**，不是 IP 共享与否——前面说过，两类套餐都给独立入口 IP 和独立出口 IP。真正的差别在计费资源上：

- **共享套餐**：按峰值带宽 + 月流量计费。流量按上行、下行**双向统计**，月额度用完服务暂停，可以自助购买流量重置或工单补差价升级。适合用量可估算、传输集中在部分时段的办公任务。
- **独享套餐**：按配置带宽计费，不设月流量额度。适合需要长时间保持稳定传输速率的任务，价格也明显更高——沪日独享入门档 200M 独享是 ¥12000/月，和 ¥358 的共享 1TB 档完全不是一个消费层级。

一个直观的对比来自沪港方向：共享入门 200Mbps 峰值 + 1024GB 流量月付 288 元；独享 5Mbps 不限流量月付 388 元。数字上前者"大"后者"小"，但 200Mbps 是峰值、不保证持续跑满，5Mbps 是独享的持续速率。短时间集中上传选前者更划算，全天候持续传输选后者才有意义。

预算估算可以用第三方测评记录做参照：广港共享款折算下来单向流量成本约每 GB 0.7~0.8 元。按这个口径估算一下团队的月度上传下载总量，基本就能锁定该选哪一档流量了。

如果拿不准，宁可先按流量计费的低档套餐跑一个月，用真实业务数据反推需求再升级——升降级走工单办理，但注意**降级到更低价格套餐时差价不退**。

## 常见问题

**这个专线能让全公司电脑都翻墙办公吗？**

不能。它是专线 VPS，你连接的是入口 IP 上的一台服务器，业务要在服务器里运行。本地电脑、手机的全部流量并不会自动走这条专线。如果需求是"给整个办公室的网络出口加速"，需要硬件专线方案。

**团队同事分布在好几个省，用直连款行吗？**

直连款入口一次只允许一个绑定省份的 IP 连入。成员分散多省的话，要么切换绑定（一次只能绑一个省），要么用 IX 方案——IX 不限连入省份，但必须从支持范围内的云厂机器接入。

**流量用超了会断网吗？**

计量型套餐按双向统计，达到额度后暂停服务，可自助购买流量重置或工单补差价升级到更高档，不会产生"静默扣费"这种意外账单。

**能部署对外网站或支付回调吗？**

不能。出口不接受外部连入，公网入站需求要另选明确支持入站的产品。

**可以先用共享套餐、以后再升级独享吗？**

可以提交工单申请，是否迁移、能否保留 IP 以工单处理结果为准；反向降级时差价不退。
